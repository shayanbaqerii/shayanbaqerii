## 🛠️ What I've been building

**Witteveen+Bos project portal** · full-stack developer · Saxion assignment, graded 9/10
A project portal for an engineering consultancy, built by a team of 6 in 9 weeks. I worked from the database schema to the React frontend, built JWT login with role-based access in Spring Security, restructured the Flyway migrations, wrote integration tests with Testcontainers, and was the team's Scrum Master.
`React 18` `TypeScript` `Spring Boot 3` `Java 21` `PostgreSQL 16` `Docker Compose` `GitLab CI/CD`

**[wellworn.nl](https://wellworn.nl)** · owner & web developer · live since October 2026
An everyday-jewellery journal I built and run myself, and the live project for my Digital Intelligence minor. I extended WordPress with custom PHP: a branded login, registration and password-reset flow on one-time keys, and an AJAX endpoint to the Brevo API. Every Amazon click is measured with a GTM trigger and a custom GA4 event.
`WordPress` `PHP` `Brevo API` `Google Tag Manager` `GA4` `Complianz`
